# Aseo Total 5

Sistema de gestión para la empresa Aseo Total 5.

## Descripción

Aseo Total 5 es un sistema de software desarrollado para apoyar
la gestión administrativa y operativa de la empresa, centralizando
diferentes procesos en una sola plataforma.

## Funcionalidades

- Gestión de empleados
- Gestión de inventario
- Control de asistencia
- Gestión de sedes
- Seguimiento de nómina
- Gestión de servicios
- Reportes
- Notificaciones

## Tecnologías

- HTML
- CSS
- JavaScript
- PHP
- MySQL
